# رادار الأسهم الحلال (نسخة الحسابات)

310 أسهم سعودية وأمريكية، سبعة مؤشرات فنية ومالية، جدول أخضر للمجتازة، اختراقات وشارتات،
تسجيل دخول (أول حساب مدير والبقية بموافقته)، قائمة متابعة خاصة بكل حساب، وأسعار تتحدث كل 15 دقيقة.

## التشغيل على Streamlit Cloud
1. ارفع كل محتويات هذا المجلد إلى مستودع GitHub، بما فيها مجلد `component` (بداخله index.html).
   من الكمبيوتر اسحب المجلد كاملًا في Add file ثم Upload files.
2. في Streamlit Cloud: اجعل **Main file path** هو `app.py` ثم Reboot.
3. **قاعدة بيانات للحسابات (مهم):** Streamlit Cloud يمسح ملفات التطبيق عند إعادة تشغيله، فتضيع الحسابات.
   - أنشئ مشروعًا مجانيًا في neon.tech وانسخ رابط الاتصال (Connection string).
   - في Streamlit Cloud افتح Settings ثم Secrets وأضف:
     ```
     DATABASE_URL = "postgresql://USER:PASSWORD@HOST/DB?sslmode=require"
     FIRST_ADMIN = "اسم_المدير_بالإنجليزية"
     ```
   - `FIRST_ADMIN` اختياري ويُنصح به: يصبح هذا الاسم وحده هو المدير عند تسجيله، فلا يستطيع غريب أن يسبقك.
     بدونه يصبح **أول من يسجل** مديرًا، فسجّل حسابك فور تشغيل التطبيق.
4. افتح التطبيق وأنشئ حساب المدير. كل حساب جديد بعده يظهر في تبويب «المدير» بانتظار اعتمادك.

## الأسعار
- أول تشغيل: جلب كامل للسجل (بضع دقائق)، ثم تحديث كل 15 دقيقة أثناء ساعات السوق:
  تداول من الأحد إلى الخميس 10:00 إلى 15:00 توقيت الرياض، والسوق الأمريكي من الاثنين إلى الجمعة.
- مرة كل يوم تقريبًا جلب كامل لتحديث النسب المالية.
- التحديث يعمل ما دام التطبيق مستيقظًا. Streamlit Cloud ينيم التطبيق بعد فترة بلا زوار، ويستأنف عند أول زيارة.
- المصدر Yahoo Finance، والأسعار متأخرة. قد تحجب Yahoo الطلبات مؤقتًا عن خوادم Streamlit المشتركة،
  وعندها يبقى آخر سعر محفوظ وتظهر ملاحظة في تبويب «المدير».

## ملفات الضبط
- `tickers.csv`: أسهم إضافية (الرمز,الاسم,السوق,القطاع).
- `halal.csv`: الحالة الشرعية من مصدر رسمي (الرمز,yes أو no). بدونه تُقدَّر من القطاع ونسب الدين والنقد.


الأداة للفرز والتحليل وليست نصيحة استثمارية.
