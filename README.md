# رادار الأسهم الحلال

منصة توصيات للأسهم السعودية والأمريكية (310 أسهم) تفحص 7 مؤشرات فنية ومالية،
وتعرض المجتازة منها في جدول أخضر مستقل، مع الاختراقات والشارتات وقائمة المتابعة.

## الطريقة 1: على جهازك (الأسهل)
1. ثبّت Python 3.9 أو أحدث، ثم:  `pip install yfinance`
2. داخل المجلد:  `python serve.py`
3. يفتح المتصفح على http://localhost:8000 . اضغط **تحديث الأسعار** (يأخذ بضع دقائق).
   تُحفظ البيانات على جهازك، ويكفي الضغط مرة يوميًا بعد الإغلاق.

## الطريقة 2: تحديث تلقائي مجاني (يصلك على الجوال والكمبيوتر)
1. أنشئ مستودعًا جديدًا على GitHub وارفع كل محتويات هذا المجلد (بما فيها مجلد `.github`).
2. من Settings ثم Pages اختر Deploy from a branch ثم main ثم root.
3. من تبويب Actions شغّل «تحديث الأسعار» مرة يدويًا. بعدها يعمل تلقائيًا كل يوم عمل بعد إغلاق السوقين.
4. افتح رابط GitHub Pages الخاص بك: تظهر الأسعار المحدّثة بلا أي خطوة منك.

## ملفات الضبط
- `tickers.csv`: أضف أسهمًا (الرمز,الاسم,السوق,القطاع).
- `halal.csv`: الحالة الشرعية من مصدرك الرسمي (الرمز,yes أو no). الأفضل الاعتماد عليها.
